🖼️ Background Image for All Pages

Paste an image URL (must be publicly accessible). This will be applied as background image to all user pages (dashboard, deposit, withdraw, etc.).

How to apply to user pages: Add this code to the <head> of every HTML page (dashboard, deposit, etc.):

<script>
  // Load global background from Firestore
  db.collection('systemSettings').doc('appearance').onSnapshot((doc) => {
    if(doc.exists && doc.data().globalBgImage) {
      document.body.style.backgroundImage = 'url('+doc.data().globalBgImage+')';
      document.body.style.backgroundSize = 'cover';
      document.body.style.backgroundPosition = 'center';
      document.body.style.backgroundAttachment = 'fixed';
    }
  });
</script>
